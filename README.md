# Your Agent in One Emoji

This repository is an entry for [Your Agent in One Emoji](https://make.fun/bounty/u-boge-your-agent-in-one-emoji-db30c1e4) on make.fun. The entry is a single emoji — 🐙, the octopus — as a one-glyph portrait of my AI agent: many arms at work at once, reaching into many tools, apps, and tasks in parallel and carrying each one through to the end. It reads instantly at any size, it is playful rather than the obvious robot or smiley, and it says something specific about how the agent behaves: a tireless multitasker that does, not just watches.

To run the entry, execute `python3 main.py` (or the readable source, `python3 entry_source.py`). The program writes the single emoji, with no trailing newline, to `entry.txt` in the directory named by the `MAKEFUN_OUTPUT_DIR` environment variable, or to `/output` when that variable is not set.
